# Painter's Eye · 看见另一种颜色

Painter's Eye 是一款本地优先的应用，帮助红绿色觉异常者在固定显示器上测量自己的辨色特点，再用世界名画瞥见画家/正常色觉者眼中的色彩关系。它先在固定显示器上测量用户的行为辨色阈值，再用未见刺激盲测转换效果。验证通过后，用户可以在内置公共领域画作上比较原始数字图像和正常视觉模拟。

Painter's Eye 不提供医学诊断，不治疗色觉异常，也不能复制正常色觉者的主观颜色体验。正常视觉模拟是一种帮助用户发现色彩关系的替代编码。

## 当前状态

这是等待首次固定显示器人体试验的 MVP 候选版。自动化验证已通过；人体感知结果尚未记录。请按 [人工显示器测试清单](docs/manual-display-checklist.md) 完成首次试验，不要用示例值代替实际结果。

## 运行要求

- Node.js 22.12 或更高版本；
- Chromium、Chrome 或其他支持 WebGL 2、IndexedDB 和 Service Worker 的现代桌面浏览器；
- 一台固定显示器。测试期间关闭自动亮度、Night Shift/夜览、True Tone/原彩、HDR 和系统色彩滤镜。

## 安装与运行

开发模式：

```bash
npm ci
npm run dev
```

可离线安装的生产版本：

```bash
npm run build
npm start
```

浏览器会显示本地地址。首次打开后，Service Worker 会缓存应用、画作、清单和图标。以后可以断网刷新画廊与查看器。请始终使用同一个地址；`localhost` 和 `127.0.0.1` 会被浏览器视为两个不同的数据空间。

## 使用流程

1. 记录显示器名称和亮度，确认系统色彩处理已关闭。
2. 完成 56 题自适应校准。四条阶梯分别测量红弱、绿弱、蓝黄控制和明暗控制方向。
3. 完成 24 题独立盲测。系统随机混合原始颜色、通用增强和个人增强。
4. 只有个人增强严格优于另外两组、且控制轴没有明显退化时，应用才保存正式配置。
5. 在画廊中先看原始数字图像，再主动开启个人增强。按住画面或空格键可以临时查看原图。
6. 换显示器、改亮度或超过复核周期后，先完成 8 题短复核。

详细方法和预先确定的成功标准见 [验证协议](docs/validation-protocol.md)。

## 本地数据与备份

应用不需要账号，也不上传回答、反应时间或配置。IndexedDB 数据库 `color-master` 保存正式配置；浏览器本地存储保存显示条件、测试草稿、复核时间和当前画作。清除该站点的浏览器数据会删除这些内容。

在“配置与备份”页面可以导出 JSON 备份。文件包含原始试次、显示条件、算法版本、验证摘要、3D LUT 和 SHA-256 校验和。导入时，应用先检查格式、版本、校验和及验证状态，再显示预览；确认前不会替换当前配置。

## 测试

```bash
npm run check
npm run test:e2e
```

`npm run check` 运行 ESLint、Vitest 和生产构建。`npm run test:e2e` 用专门的 `e2e` 构建执行缩短且确定的浏览器旅程；这个模式只测试流程，不替代完整的人体校准，普通开发和生产构建不会启用它。

## 方法概要

- 刺激：带随机点阵的四方向 Landolt C；几何、颜色中心和方向由种子复现。
- 阶梯：每条轴采用“两次正确下降、一次错误上升”，并记录方向反转。
- 拟合：结合最后试次、回答正误、反转点、重复一致性和控制轴，生成有界行为配置。
- 色彩模型：在线性 sRGB 中使用 Machado 色觉异常模拟矩阵，在 OKLab 中把易丢失的红绿细节有限地重编码到较强的通道，并约束明度、色域和蓝黄控制差异。
- 渲染：17×17×17 3D LUT；优先 WebGL 2，失败时使用 CPU。强度 0% 直接显示原始数字图像。

模型出处和实现说明见 [色彩模型参考](src/color/README.md)。本工具使用的是行为个性化类别，不等同于临床分型或严重程度。

## 内置画作与许可

应用内置多幅公共领域作品，来源为耶鲁大学美术馆和大都会艺术博物馆。每个文件的来源地址、尺寸、处理方式和 SHA-256 摘要记录在 [画作清单](public/artworks/manifest.json) 中。应用只预缓存本地副本，不缓存外部博物馆页面。

## 已知限制

- 配置只适用于记录时的显示器、亮度、系统色彩设置和相近环境光。
- 普通消费显示器不是医疗校准设备；浏览器、ICC 配置、面板老化和环境光都会影响结果。
- 当前模型使用全局变换，不理解画中物体，也不保证所有作品在同一强度下都自然。
- 博物馆数字图像不等于实体作品在现场照明下的绝对颜色。
- 盲测证明的是当前任务上的辨别改善，不证明用户获得了“正常人的颜色”。
- 首次人体试验完成前，本版本应标记为实验性 MVP 候选版。
