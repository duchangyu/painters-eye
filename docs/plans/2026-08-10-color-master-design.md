# Color Master 个性化色彩补偿设计

日期：2026-08-10
状态：MVP 候选版已实现并通过自动化验证；固定显示器人体试验待执行

## 1. 产品目标

Color Master 面向红绿色觉异常用户。它通过个体视觉测试建立补偿配置，再把配置应用于公共领域画作，帮助用户察觉容易遗漏的红绿色彩差异。

产品不声称恢复正常色觉，也不声称复制正常色觉者的主观体验。第一版追求一个可验证的结果：在固定电脑和显示器上，提高用户辨别未见颜色刺激和画作色彩分区的能力，保持画面自然，不损害蓝黄、明暗等原本可辨的信息。

## 2. 已确认原则

- 准确度优先，用户愿意用约 10–15 分钟完成首次校准。
- 第一版服务于同一台电脑和显示器；跨设备一致性留待以后处理。
- 原始数字图像始终保留且不被修改。
- 默认提供内置精选画作，不要求用户自行寻找或上传图片。
- 对比以同一位置快速切换为主：按住查看原始图，松开显示增强图。
- 配置保存在本机，可长期复用；正常情况下无需重复完整校准。
- 第一版完全本地运行，无需注册账号，不上传色觉数据。
- 结果页展示详细测量数据，不用模糊的“校准成功”代替证据。

## 3. 用户流程

### 3.1 首次使用

1. 产品说明：这是个性化色彩补偿工具，不提供医学诊断。
2. 显示环境检查：提示固定屏幕亮度，并关闭夜览、原彩、护眼及系统色彩滤镜。
3. 自适应校准：用户完成约 10–15 分钟的随机图形辨认任务。
4. 独立验证：使用校准阶段从未出现过的刺激，盲测个人增强是否优于原图和通用增强。
5. 生成配置：验证通过后保存个人模型、转换表和可信度。
6. 进入内置画廊，默认先查看原始数字图像，再主动开启个人增强。

校准过程自动保存为草稿。中途退出后可以继续，但草稿不能作为正式补偿配置使用。

### 3.2 再次使用

1. 自动载入本机个人配置。
2. 提醒用户恢复校准时的显示器与亮度设置。
3. 在显示环境变化或复核周期到期时，完成约 1–2 分钟的 8 题一致性检查。
4. 结果稳定时直接进入画廊；检测到显示器或表现明显变化时，提示完整重校准。

## 4. 个体校准

校准不复制固定的石原氏色盲检查卡。系统生成随机点阵和四方向 Landolt C 开口刺激，防止用户记住答案，也防止模型只适应少数卡片。

测试采用强迫选择与自适应阶梯法。系统根据上一题回答，沿红弱、绿弱及若干交叉颜色方向自动调整色差，反复逼近用户“刚好能够辨认”的阈值。刺激应覆盖多个颜色中心、饱和度和亮度，而不是只测试单一红绿组合。

校准过程中，系统随机重复一部分条件，以估计前后一致性和不确定度。MVP 为每条轴设置固定安全题量；反转不足或回答冲突会降低可信度。正式配置仍须通过后续独立盲测。

校准输出包括：

- 红绿混淆的主要方向；
- 不同颜色区域的辨别阈值；
- 重复测试一致性；
- 模型参数及其可信度；
- 个性化颜色转换表；
- 尚不能可靠补偿的颜色范围。

## 5. 色彩补偿

简单增加 RGB 红色或绿色通道不能完成补偿。系统应在线性光和锥体/对立颜色表示中估计需要扩大或重新编码的色彩差异，再生成实时渲染所需的转换表。

第一版优先采用全局、可解释且程度可调的个性化变换。它需要在两项目标间优化：

1. 提高用户可感知的颜色对比；
2. 保持原图亮度结构和总体自然度。

用户可使用 0%–100% 强度滑杆。0% 必须显示未处理的原始数字图像；推荐值来自校准结果；100% 表示当前模型允许的完整补偿强度。原图文件保持不可变，所有增强仅发生在显示阶段。

## 6. 内置画廊

第一版内置约六幅具有明确测试价值的公共领域或 CC0 作品。图片来自博物馆或可信开放馆藏；每幅作品保存标题、作者、年代、来源链接、许可状态和选择理由。

建议首批作品：

- [梵高《夜间咖啡馆》](https://artgallery.yale.edu/collections/objects/12507)：高饱和红墙与绿色台球桌，测试强烈红绿冲突。
- [梵高《玫瑰》](https://www.metmuseum.org/art/collection/search/436534)：浅粉花朵与绿色叶片在低对比背景中重叠；大都会艺术博物馆标记为公共领域。实现阶段因芝加哥艺术博物馆图像服务在采集环境中返回交互式验证页，改用该作品，未绕过来源限制。
- [塞尚《苹果与梨》](https://www.metmuseum.org/art/collection/search/435883)：测试红、绿、黄、棕之间的细微区别；大都会艺术博物馆标记为公共领域。
- [梵高《夹竹桃》](https://www.metmuseum.org/art/collection/search/436530)：测试花朵、叶片等小面积交织色彩；大都会艺术博物馆标记为公共领域。
- [梵高《采橄榄的女人》](https://www.metmuseum.org/art/collection/search/436536)：测试低饱和灰绿和土色；大都会艺术博物馆标记为公共领域。
- [北斋《神奈川冲浪里》](https://www.metmuseum.org/art/collection/search/56353)：作为蓝色主导的控制作品，检查补偿是否破坏非目标色彩关系；大都会艺术博物馆标记为公共领域。

界面使用“原始数字图像”而非“原画”一词，避免暗示博物馆数字复本与实体作品的绝对颜色完全相同。上传自有图片可保留为次要入口，但不是首次体验的必需步骤。

## 7. 画作查看器

作品打开时默认显示原始数字图像。用户主动开启个人增强后，可进行以下操作：

- 按住鼠标临时显示原始图，松开恢复增强图；
- 使用强度滑杆连续调整补偿程度；
- 放大查看局部笔触与色彩区域；
- 使用辅助的左右并排模式；
- 查看作品的色彩关系说明及选择理由。

用户完成自主观察后，界面才显示色彩说明，以免提示影响体验。说明描述多数正常色觉者常见的色彩关系和艺术作用，不把增强后的替代颜色称为“真正的正常颜色”。

## 8. 技术架构与数据流

第一版采用本地优先的网页应用，由以下模块组成：

- 校准引擎：生成刺激、执行自适应测试并记录回答。
- 个体模型：估计阈值、混淆方向、不确定度并生成转换表。
- 配置存储：保存草稿、原始试验数据、正式配置和算法版本。
- 图像渲染器：通过 GPU 着色器实时应用转换表，并提供 CPU 降级路径。
- 内置画廊：本地提供开放许可图像和结构化作品信息。

核心数据流：

`检查卡回答 → 辨别阈值 → 个体色觉模型 → 颜色转换表 → 实时增强画作`

渲染器只读取源图像。切换、强度变化和按住对比均通过显示参数完成，不写回或覆盖源文件。

## 9. 配置保存与隐私

浏览器本地数据库保存正式配置；本地存储保存未完成进度和显示条件。数据包括：

- 未完成测试进度；
- 每次刺激参数、用户回答和反应时间；
- 拟合模型、阈值与可信度；
- 颜色转换表；
- 校准日期、显示设置和有限的设备特征；
- 数据格式及算法版本；
- 独立验证结果。

用户可导出和导入本地配置文件。由于配置保留原始试验数据，算法升级后可以重新拟合模型，通常无需重做完整测试。

第一版无服务器账户、分析追踪或云同步。所有色觉数据留在本机。

## 10. 错误与异常处理

- 未完成校准：保存草稿，不生成正式补偿配置。
- 测试前后不一致：自动增加相关条件的题目并降低可信度。
- 更换显示器或显著改变显示设置：暂停自动应用旧配置并提示复测。
- 快速一致性检查失败：允许查看原始图，但建议完整重校准后再启用增强。
- WebGL/GPU 不可用：使用较慢的 CPU 图像处理路径。
- 配置版本过旧：优先使用原始回答重新计算；无法迁移时保留备份并提示重校准。
- 内置资源缺失：显示作品信息与明确错误，不以无来源的网络图片替代。

## 11. 验证与成功标准

### 11.1 行为验证

独立验证必须使用未见刺激，并以随机顺序盲测：

- 原始颜色；
- 通用红绿增强；
- 个性化增强。

个性化增强必须在正确率或识别时间上稳定优于原图和通用增强。蓝黄、黑白和低饱和控制任务不得明显退化。

画作验证从内置作品提取代表性区域，测试用户能否发现正常色觉观察者标注的重要色彩分区，同时收集自然度反馈。

### 11.2 软件验证

- 0%/原始模式不改变源图像像素数据。
- 相同配置在保存、关闭、重新载入后产生一致输出。
- 校准草稿可以安全恢复。
- 离线状态下校准、画廊和配置均可使用。
- GPU 路径与 CPU 降级路径的结果在允许误差内一致。
- 旧配置迁移和损坏配置不会覆盖原始数据。

### 11.3 结果展示

结果页展示三种条件的正确率和中位识别时间，以及各方向阈值、重复一致性、可信度及剩余局限。结论只使用本次真实数据，不填入说明性数值。

## 12. 技术与研究依据

- [美国国家眼科研究所：Color Blindness](https://www.nei.nih.gov/eye-health-information/eye-conditions-and-diseases/color-blindness)：区分治疗、辅助辨色和视觉工具的适用范围。
- [Cambridge Colour Test 原始论文](https://vision.psychol.cam.ac.uk/jdmollon/papers/ReganReffinMollonCambridgeColourTest.pdf)：用辨别阈值量化 protan、deutan 和 tritan 方向。
- [数字显示器上的 Ishihara 测试研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11287189/)：说明显示设备会影响数字测试的敏感度与特异度。
- [个性化图像重着色研究](https://doi.org/10.1109/TMM.2021.3070108)：根据异常三色觉程度平衡对比增强与画面自然度。
- [个性化 Daltonization 研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8321179/)：展示个体化重着色及独立行为验证的思路。

## 13. 第一版范围外事项

- 医学诊断或治疗建议；
- 保证复制正常色觉者的主观颜色体验；
- 多显示器和跨设备配置迁移；
- 系统级全屏颜色滤镜；
- 云端账户和自动同步；
- 大规模在线博物馆浏览；
- 内容感知或逐区域的复杂重着色；
- 自动声称某个补偿强度对所有画作都最优。

这些能力可以在固定显示器上的个体校准、验证和画作体验被证明可靠后再评估。
